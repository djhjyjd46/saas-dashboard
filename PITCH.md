## Контактная информация для ответов

**На вопрос "Как это работает?"**
> Система автоматически подключается к Яндекс.Директу через OAuth, получает информацию по каждой кампании и их дневную статистику. Параллельно синхронизирует лиды из амоCRM. На дашборде всё это объединяется — видишь, сколько потратил на кампанию, сколько получил лидов, сколько из них стали сделками и какой был доход. Администратор может настроить, какие кампании видит каждый пользователь.

**На вопрос "А безопасно?"**
> Да, платформа построена на Laravel — один из самых безопасных фреймворков. Все API токены зашифрованы. Данные полностью изолированы по Tenant (рабочая область), никакой доступ между пользователями. Каждый видит только то, что ему разрешено администратором. CSRF-защита, защита от SQL-injection, поддержка HTTPS.

**На вопрос "Как быстро отключится/переходит на что-то ещё?"**
> Все данные хранятся в БД, которую клиент может взять в любой момент. Export функции есть. Бэкапы автоматические. Миграция на другую систему — вопрос 1-2 дней.

**На вопрос "Сколько это стоит?"**
> (Обсудить с владельцем) — зависит от объёма кампаний и количества пользователей. Может быть на основе SaaS-подписки (месячная фиксированная сумма) или one-time implementation + техподдержка.
